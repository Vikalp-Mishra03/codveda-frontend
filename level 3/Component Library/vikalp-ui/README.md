# Vikalp UI

A reusable and accessible React component library built for modern web applications.

Vikalp UI provides simple, customizable, and responsive UI components that can be reused across React projects.

## Features

- ♻️ Reusable React components
- 🎨 Customizable variants and sizes
- 📱 Responsive components
- ♿ Accessibility-focused implementation
- 📚 Storybook documentation
- 📦 NPM package support
- ⚡ Built with React and Vite

## Components

Vikalp UI currently includes:

- Button
- Input
- Card
- Modal
- Navbar
- Badge
- Alert
- Spinner

## Installation

Install Vikalp UI using npm:

```bash
npm install vikalp-ui
